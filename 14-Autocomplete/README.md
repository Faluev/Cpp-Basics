# Практическая 14.11 · Автодополнение слов

Консольная программа C++ подставляет слова из заданного словаря по введённому началу. Словарь указан в `main.cpp` и при запуске строится как префиксное дерево (`Trie`). У каждого узла есть ветви для букв A–Z и признак конца слова. Поиск доходит до узла введённого префикса и рекурсивно обходит его потомков.

## Запуск

1. Откройте `Autocomplete.vcxproj` в Visual Studio 2022 с компонентом «Разработка классических приложений на C++».
2. Выберите `Debug | x64` или `Release | x64` и запустите Ctrl+F5.
3. Введите `gam` и нажмите Enter. Появятся `game`, `gamepad`, `gameplay` и `gamer`.
4. Введите номер слова. Программа покажет выбранное слово и снова попросит префикс. `0` возвращает к вводу префикса, `:quit` завершает программу.

Ввод учитывает только английские буквы и допускает оба регистра. Точное слово включается в подсказки вместе с более длинными совпадениями. Префикс `xyz` выдаёт сообщение об отсутствии подсказок.
