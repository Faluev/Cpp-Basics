# Практическая 12.8 · Проверка кратности строки

Функция `IsKPeriodic(text, k)` проверяет, состоит ли строка из одинаковых блоков длиной `k`. Например, `IsKPeriodic("abcabcabcabc", 3)` возвращает `true`.

Если `k` положительно и длина строки делится на `k`, функция сравнивает каждый символ после первого блока с символом на `k` позиций левее. При первом несовпадении проверка заканчивается. Для строки длиной `n` это даёт время `O(n)` в худшем случае и `O(1)` дополнительной памяти.

Для пустой строки и `k <= 0` функция возвращает `false`. Если `k` равно длине непустой строки, она считается одним блоком. Сравнение учитывает регистр и пробелы. Для `std::string` длина измеряется в элементах `char`.

Откройте `KPeriodic.vcxproj` в Visual Studio 2022, выберите `Debug | x64` или `Release | x64` и нажмите Ctrl+F5. `main.cpp` выводит результат на примерах и возвращает ненулевой код при расхождении с ожидаемым ответом.
