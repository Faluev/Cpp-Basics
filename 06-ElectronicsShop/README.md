# Магазин электроники

Практическая работа 6.7 по основам C++. Пользователь выбирает товар по номеру и видит его характеристики. Команда `0` завершает программу.

## Запуск

Откройте `ElectronicsShop.vcxproj` в Visual Studio, выберите `Debug | x64` и нажмите Ctrl+F5. Для запуска готового файла в классической командной строке Windows установите UTF-8 командой `chcp 65001` и запустите `x64\Debug\ElectronicsShop.exe` из папки проекта.

## Классы

- Абстрактный `Electronics` задаёт общий метод `showCharacteristics()`.
- `Television` наследуется от `HomeAppliance`, а `Headphones` — от `PortableDevice`.
- `CordlessVacuum` наследуется от обеих ветвей и показывает мощность и время работы от аккумулятора. Виртуальное наследование оставляет в нём одну общую часть `Electronics`.
- Товарный склад — обычный массив указателей `Electronics*`. При выборе товара виртуальный метод выводит характеристики соответствующего класса.
