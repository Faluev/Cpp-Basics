# IntegerArray

Практическая 7.7 по основам C++. `IntegerArray` хранит целые числа в динамическом массиве. Копирование создаёт независимый массив. `resize` сохраняет элементы, которые помещаются в новый размер, и заполняет новые позиции нулями.

- `getLength()` возвращает текущий размер. Размер `0` соответствует пустому массиву.
- `array[index]` и `remove(index)` принимают индексы от `0` до `getLength() - 1`.
- `insertBefore(value, index)` принимает также индекс `getLength()` для вставки в конец.
- `bad_range` сообщает о недопустимом индексе. `bad_length` сообщает об отрицательной длине или невозможности увеличить размер в пределах `int`. Оба наследуются от `std::exception`.

Откройте `IntegerArray.vcxproj` в Visual Studio, выберите `Debug | x64` или `Release | x64` и нажмите Ctrl+F5. `main.cpp` запускает проверки и возвращает ненулевой код при сбое.
